# Pushkar Pant Portfolio — Frontend

Premium light-theme React + TypeScript portfolio frontend.

## Stack
- React + TypeScript + Vite
- Three.js + React Three Fiber + Drei
- GSAP
- Lenis
- Lucide React

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Backend integration
The contact form is currently a frontend preview. Connect it to the planned Spring Boot API.
Replace the résumé placeholder at `public/Pushkar_Pant_Resume.pdf` with the final PDF.
